Rebuilding Jev
A model that never writes a sentence
You send
{
 "document":
   "my bill was charged twice",
 "questions": {
   "category": ["billing",
    "technical", "sales", "spam"],
   "urgent": ["yes", "no"]
 }
}
You declare the options. That list is the contract.
The model sees
mybillwascharged twicepleasehelp billingtechnicalsalesspam
One flat sequence. The options are appended as ordinary words, so the model reads the document and the candidate answers together, in a single pass with no generation loop.
You get back
category
billing
p = 0.59
urgent
yes
p = 0.88
confidence
0.41
low, route to a human
Typed values, not text. Every set sums to 1 over the options you listed, so there is nothing to parse.
